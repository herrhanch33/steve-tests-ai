7.8 s → 2.2 s per answer: same model, same 2x RTX 3090, new engine

Same 3-bit model, same two RTX 3090s: 7.8 s to 2.2 s per answer.

About this video

I run a 3-bit quantized large language model on two RTX 3090s at home. In my Nov 7, 2026 exactness tests, switching the inference engine (llama.cpp to Strata, same model file) cut the median time per answer from 7.8 s to 2.2 s. Speed numbers in the video: same model file, 128K context, one slot; the Strata run also had vision off. My live setup today is slower than that test, and the video says so.

The numbers, with their setups

  • 7.8 s → 2.2 s: median time per answer (Median time per answer in my Nov 7, 2026 exactness tests. Same model file, new engine; the new run also had vision off.)
  • Reading a 57K-token document (tokens per second): llama.cpp 695 vs Strata 3,935 (Same 3-bit model, 2x RTX 3090, 128K context, one slot. Nov 7, 2026.)
  • ~290 s → 81 s: one multi-agent team run (Same job, same model. Nov 7, 2026.)
  • 98 → 99: of 100 math questions right: no drop (First 100 GSM8K questions. One question of difference is noise, not an improvement.)
  • 24 / 24: runs clean in a 2-hour soak test (Soak test, Nov 7, 2026. No GPU errors.)
  • 4 min vs 1 min: the catch: first start (First start of the new engine vs llama.cpp, Nov 7, 2026.)
  • 93 tok/s: what I actually run today (Measured Nov 15, 2026. One slot, same Nov 15 settings: about 125. Four at once: about 45 each.)
